# Дубликатор марок (Python + Zint)

Небольшое приложение, которое принимает строку КМ, нормализует её и строит GS1 DataMatrix для повторной печати.

## Требования

- Python 3.10+
- Установленный `zint` (утилита генерации штрихкодов)
  - Windows: установить Zint и добавить `zint.exe` в `PATH` (либо положить `zint.exe` рядом с `app.py`, либо задать переменную `ZINT_PATH`)
  - Ubuntu: `sudo apt install zint`

## Лицензия Zint (важно для GitHub)

Проект использует внешний инструмент **Zint**:

- **zint (CLI) и GUI**: лицензия **GPLv3 или позже**
- **libzint (библиотека)**: лицензия **BSD-3-Clause**

Поэтому обычно **не кладут `zint.exe` в репозиторий**, а добавляют в инструкцию установку Zint и ссылку на официальный проект: `https://github.com/zint/zint`.

## Установка зависимостей Python

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

## Формат входной строки

Поддержан частый формат (как у вас):

`01<GTIN14>21<SN(6)>93<CHECK(4)>`

Приложение автоматически вставит разделитель GS (ASCII 29) между `21` и `93` и передаст данные в Zint в режиме GS1.
